-- To add a new local branch from a remote branch

1. git remote add <remote_name> <repo_url>
2. git fetch <remote_name>
3. git checkout -b <new_branch_name> <remote_name>/<remote_branch_name>

Example
1. git remote add remotes/origin/Production/12.5  --This line is not needed
2. git fetch remotes/origin/Production/12.5 -- This line is not needed
3. git checkout -b Dev/maliao/WellsFargo12.5/Installer remotes/origin/Production/12.5  --This is the only line needed


-- To delete a local branch
git branch -d <branch name>

-- To discard changes in working directory
git restore <file> or git restore .

-- How to use stash
Command	What it does
git stash			Saves your changes and cleans the working directory.
git stash push -m "message"	Saves a stash with a custom name (highly recommended).
git stash list			Shows all stashed items in a list (like stash@{0}, stash@{1}).
git stash pop			Applies the most recent stash and deletes it from the list.
git stash apply			Applies the stash but keeps it in the list (safer).
git stash drop			Deletes a specific stash without applying it.
git stash clear			Deletes all stashes forever.

-- Remove already uploaded .vs/ folders to GitHub and stop tracking them
git ls-files -z | grep -z '\.vs/' | xargs -0 git rm --cached -r
git status   # confirm only deletions from the index + .gitignore if changed
git commit -m "Stop tracking Visual Studio and build artifacts"
git push

After this, .vs/, bin/, obj/, etc. stay on your machine but no longer appear in GitHub.
